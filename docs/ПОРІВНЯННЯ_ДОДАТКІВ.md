# Порівняльна таблиця функціоналу PWA vs Android

## 1. АВТОРИЗАЦІЯ ТА ВЕРИФІКАЦІЯ

| Процедура | PWA | Android |
|-----------|-----|---------|
| **Верифікація телефону (Firebase OTP)** | ✅ `sendVerificationCode()`, `verifyOtpCode()` | ✅ `PhoneVerificationActivity` |
| **Авто-визначення SIM** | ❌ | ✅ `SubscriptionManager` (Dual-SIM) |
| **Реєстрація** | ✅ `handleRegister()` → `POST /pwa/register` | ✅ `RegisterActivity` → `POST /api/v1/auth/register` |
| **Логін** | ✅ `handleLogin()` → `POST /pwa/login` | ✅ `LoginActivity` → `POST /api/v1/auth/login` |
| **Авто-логін (Remember Me)** | ✅ localStorage token | ✅ SecurePreferences + 24h token check |
| **Вихід** | ✅ `logout()` | ✅ `POST /api/v1/auth/logout` |
| **Скидання пароля** | ✅ `startPasswordReset()` → `POST /api/v1/auth/reset-password` | ✅ `ForgotPasswordActivity` → `POST /api/v1/auth/reset-password` |
| **RSA шифрування даних** | ❌ (plain text) | ✅ `RSAEncryption` для phone/password |
| **E2E шифрування відповідей** | ❌ | ✅ AES ключ через RSA |
| **Отримання JWT токену** | ✅ | ✅ |
