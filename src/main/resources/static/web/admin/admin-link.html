💡 Як використовувати:

Варіант 1 (Швидкий):

1. Натисни "Завантажити мої групи"

2. Вибери групу зі списку

3. Автоматично відкриється Dashboard


Варіант 2 (Ручний):

1. Введи ID групи (з Postman або з бази)

2. Введи JWT токен (з localStorage або з /auth/login)

3. Натисни "Згенерувати посилання"

4. Посилання відкриється автоматично
